# Skymoni 账户 · DeepSeek Harness 桌面插件

在 DeepSeek Harness 桌面端左侧打开 **Skymoni 账户登录**，查看积分、每日签到和本机用量。授权后可在 DSH 原生模型选择器里选择 **Skymoni** 的模型。

## 安装

支持 DeepSeek Harness 桌面版 **0.2.1-rc.2** 和 **0.2.2-rc.5**。用本地包安装时，打开 **插件 → 添加插件**，输入 `.tgz` 文件的完整路径。通过 npm 安装时输入插件名称。

```text
dsh-plugin-skymoni
```

安装后按 DSH 的提示刷新插件或重启桌面端。

## 使用

1. 点击左侧带头像的 **Skymoni 账户登录**。
2. 选择 **使用 Skymoni 账户登录**，打开网站授权页，用原有签到账户确认。
3. 回到插件页查看可用积分、累计消耗、累计请求和有效订阅。选择 **立即签到** 完成当天签到。官网要求验证时，通过同一张卡片打开官网继续。
4. 在会话输入框的模型选择器中选择 **Skymoni** 下的模型。如需切换账户，可在用量管理页底部退出。

模型目录同时核对当前账户的对话模型和令牌可调用的模型。推理、工具调用和结算继续通过 DSH 与 Skymoni 各自的原有机制处理。

## 账户和凭据

密码与网站登录 Cookie 由 `skymoni.com` 处理。插件把自己的设备授权会话保存在 DSH 原生凭据服务的 `skymoni-account/session` 记录中。DSH 默认文件凭据服务的保护方式取决于用户的安装环境。

当前站点接口返回同一账户的 Skivu 专用 API Key。插件仅在宿主进程内存中持有该 Key，每次模型调用前验证设备会话。退出会清除插件授权并尝试撤销对应的设备会话。Skivu 专用 API Key 继续供同账户既有客户端使用。

该插件访问 `https://skymoni.com` 的授权、账户、签到、模型目录和推理接口。签到由用户点击触发。

使用日历和可导出的明细从本版本开始记录本机经插件发出的 Skymoni 请求。记录按账号保存在 DSH 本地存储中，最多保留近一年内的 5,000 条时间、模型、已知 Token 数和请求状态。CSV 导出到当前用户的 Downloads 目录，页面会显示完整保存路径。积分消耗以账户账单为准。

## 开发验证

使用 Node.js 24.9+，分别装入 DSH 0.2.1-rc.2 和 0.2.2-rc.5 对应依赖运行 `npm run check`、`npm test` 和 `npm pack`。测试使用合成账户及模型响应。许可证见 `LICENSE.txt` 和 `THIRD_PARTY.md`。
